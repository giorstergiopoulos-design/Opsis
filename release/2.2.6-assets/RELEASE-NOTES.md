# Opsis 2.2.6

## Ελληνικά
- Στοιχεία wallpaper: το GPU δείχνει κάθε προσαρμογέα γραφικών (αποκλειστικό + ενσωματωμένο).
- Θέματα ρολογιού (Classic, Minimal, Neon, Mono, Retro), χρώμα μπαρών, θέση «Κέντρο».
- Το αναλογικό ρολόι του wallpaper είναι κεντραρισμένο.
- Διόρθωση: με τη διαγραφή container τα εικονίδια επιστρέφουν στην επιφάνεια· κουμπιά Νέο/Διαγραφή container και προφίλ στο κύριο παράθυρο.
- Υπόλοιπα: δείτε το CHANGELOG.

## English
- Wallpaper elements: the GPU element lists every graphics adapter (dedicated + integrated).
- Clock themes (Classic, Minimal, Neon, Mono, Retro), bar colour, centre placement.
- The wallpaper analog clock is centred.
- Fix: deleting a container returns its icons to the desktop; New/Delete container and profile buttons in the main window.
- Open items: see CHANGELOG.

SHA-256: see `OpsisSetup.exe.sha256` · `Get-FileHash OpsisSetup.exe -Algorithm SHA256`
