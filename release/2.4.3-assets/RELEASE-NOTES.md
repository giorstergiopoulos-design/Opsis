# Opsis 2.4.3

## Ελληνικά
- Νέο προαιρετικό συμβόλαιο plugin: ένα plugin μπορεί να αντικαταστήσει το ενσωματωμένο ημερολόγιο και να δημοσιεύει ροές κειμένου (πρώτο plugin: Χρονικολόγιο «Σαν σήμερα»).
- Workflow plugin-e2e στο CI. Υπόλοιπα: δείτε το CHANGELOG.

## English
- New optional plugin contract: a plugin can replace the built-in calendar widget and publish text feeds (first plugin: Chronicle "On this day").
- plugin-e2e workflow in CI. Open items: see CHANGELOG.
