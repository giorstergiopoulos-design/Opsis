# Opsis 2.3.0

## Ελληνικά
- Ρυθμίσεις σε εμφάνιση Windows 11: γραμμές με διακόπτη, αναζήτηση σε κάθε σελίδα, κουμπί Επαναφορά ανά ενότητα (σελίδα Ρυθμίσεων), ένδειξη «Απαιτείται επανεκκίνηση».
- Με εγκατεστημένα και τα δύο plugins το παράθυρο μεγαλώνει ώστε να φαίνονται όλες οι καρτέλες του πλευρικού μενού.
- Υπόλοιπα 2.3.1: δείτε το CHANGELOG.

## English
- Windows 11 style settings: switch rows, a search box on every page, a Reset button per section (Settings page), a "Restart needed" tag.
- With both plugins installed the window grows so every side-menu tab is visible.
- Open items for 2.3.1: see CHANGELOG.

SHA-256: see `OpsisSetup.exe.sha256` · `Get-FileHash OpsisSetup.exe -Algorithm SHA256`
